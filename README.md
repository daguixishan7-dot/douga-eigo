# 英語の動画帳

TED の講演を、英語字幕と日本語訳で見ながら、単語を押して意味を調べるための個人の勉強用ページです。広告や収入はありません。

- 字幕: TED の英語字幕と TED Translators の日本語訳。TED Talks は [CC BY-NC-ND 4.0](https://www.ted.com/about/our-organization/our-policies-terms/ted-talks-usage-policy) で公開されています。訳した人の名前は動画ごとにページに出しています
- 動画: YouTube の埋め込みプレーヤーで再生します
- 辞書: [EJDict](https://github.com/kujirahand/EJDict)（くじらはんど、CC0）
